# Anjos de Patas

## Sobre o projeto
O Anjos de Patas é um sistema web desenvolvido para uma ONG de proteção animal, com o objetivo de divulgar projetos e facilitar o cadastro de pessoas interessadas.

## Funcionalidades
- Página inicial.
- Apresentação dos projetos.
- Formulário de cadastro.
- Área administrativa.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Como executar
Abra o arquivo index.html em um navegador para visualizar o sistema.
